# HANDOFF: школьный помощник «Учёба»

Файл для продолжения работы в новом чате (с Claude, Groq-моделью или другим ИИ). Вставь его целиком в начало нового диалога.

## Цель
Личный сайт для школьника, чтобы эффективнее учиться и повторять темы дома. Работает с телефона. Сейчас им пользуется один человек, позже возможно друзья.

## Контекст владельца
- Электронный дневник: **Edupage** (официального API для учеников нет).
- Предметы на русском, кыргызском (как предмет) и английском. Английские темы нужно уметь объяснять и переводить на русский.
- Домашки в школе нет, он сам повторяет дома. Часто забывает темы, пройденные давно.
- Нужно: оценки с датой (дату и тему можно дописать позже), пропуски, темы уроков, понимание, где слабые места.
- Разработка на Windows 10. Раньше деплоил на Vercel (React/Vite).

## Принятые решения
- Сайт, а не приложение. Открывается на телефоне, позже можно сделать PWA.
- ИИ: **Groq API** (модель по умолчанию `llama-3.3-70b-versatile`, меняется переменной `GROQ_MODEL`). Если упёрся в лимит, продолжать на следующий день.
- Данные пока в `localStorage` браузера. Оценки из Edupage забираются кнопкой «Импорт из Edupage» через неофициальную библиотеку `edupage-api` (https://github.com/EdupageAPI/edupage-api). Пропуски и темы вводятся вручную.
- Ключ Groq только на сервере (`api/ai.py`), никогда во фронтенде.

## Что уже сделано (v0.1)
- `index.html`: один файл, без сборки. Вкладки: Оценки, Пропуски, Темы, Слабые места, Предметы.
  - Оценки: предмет, оценка 5-2, дата и «за что» необязательны. Записи без темы подсвечиваются «Допиши». Можно редактировать и удалять.
  - Пропуски: дата, причина, отметка «Тему нагнал».
  - Темы: что прошли, кнопки ИИ (Конспект, Тест, Объясни проще), отметка «Повторил» с датой.
  - Слабые места: счёт по предмету = низкий средний балл + оценки 3 и ниже + ненагнанные пропуски + темы, не повторявшиеся больше 14 дней.
  - Предметы: добавить/удалить, скачать/загрузить резервную копию JSON.
- `api/ai.py`: Vercel-функция, обращается к Groq. Если задан `APP_PASSWORD`, требует пароль (спросит один раз на сайте).

## Структура
```
study-helper/
  index.html     всё приложение (HTML + CSS + JS)
  api/ai.py      функция ИИ (Groq), Python
  api/edupage.py функция импорта оценок из Edupage, Python
  server.py      локальный запуск (python server.py)
  requirements.txt  зависимости (edupage-api)
  .env.example   образец файла .env с ключом Groq
  vercel.json    лимит времени для edupage.py
  HANDOFF.md     этот файл
```

## Модель данных (localStorage, ключ `uchyoba`)
```
subjects: [{id, name}]
grades:   [{id, sid, v, date, note}]        // date и note могут быть пустыми
abs:      [{id, sid, date, reason, done}]
topics:   [{id, sid, date, text, rev}]      // rev = дата последнего повторения YYYY-MM-DD
```

## Локальный запуск (Windows)
1. Установить Python 3.9+ (python.org, галочка Add to PATH).
2. В папке проекта: `pip install edupage-api`
3. Скопировать `.env.example` в `.env` и вписать ключ Groq (без него не работают кнопки ИИ, импорт оценок работает).
4. `python server.py`, открыть http://localhost:8000
5. Вкладка «Оценки»: ввести школу (поддомен), логин и пароль Edupage, нажать «Загрузить оценки».

## Как запустить на Vercel
1. Залить папку `study-helper` в GitHub-репозиторий.
2. Vercel: New Project, выбрать репозиторий. Сборка не нужна.
3. В Settings > Environment Variables добавить:
   - `GROQ_API_KEY` (ключ с console.groq.com)
   - `APP_PASSWORD` (любой пароль, чтобы чужие не тратили твой лимит)
   - `EDUPAGE_USER`, `EDUPAGE_PASS`, `EDUPAGE_SCHOOL` (логин, пароль и поддомен школы: часть адреса перед `.edupage.org`)
   - `GROQ_MODEL` (необязательно)
4. Redeploy. Открыть сайт на телефоне, «Добавить на главный экран».

## Известные ограничения
- `edupage-api` неофициальная и может сломаться при обновлении Edupage. Текстовые оценки (не 2-5) при импорте пропускаются. Если оценка нестандартного типа, библиотека может упасть целиком (известная ошибка).
- Пароль от Edupage только в переменных окружения Vercel, не в коде и не в чате. Библиотека под лицензией GPL-3.0, для личного использования это не мешает.
- Данные живут только в браузере. Очистка данных сайта сотрёт всё, поэтому периодически скачивай резервную копию во вкладке «Предметы».
- Ответы ИИ показываются обычным текстом, без форматирования.
- Лимиты бесплатного Groq небольшие. При ошибке лимита подожди до следующего дня.
